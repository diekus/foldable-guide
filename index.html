About this demo

Foldable Guide is a starting point for foldable-ready web apps, built with plain HTML, CSS and JavaScript.

  • Book style (Galaxy Z Fold, Pixel Fold, foldable iPhone): panes sit side by side, one per segment.
  • Flip style / tabletop (Galaxy Z Flip, Razr): panes stack, one per segment.
  • Dual-screen (Surface Duo): content stays clear of the hinge.

No foldable? In Chrome DevTools, open device emulation and pick a foldable device, or use the Sensors panel to change the posture.
